ดู embed JSON ที่จะส่งเข้า Discord จริง (ตามดีไซน์ที่เลือก)


    

      ข้อจำกัดของ Discord embed ที่ดีไซน์ต้องอยู่ในกรอบ

      · title ไม่รองรับ markdown (ตัวหนา/โค้ดใช้ได้เฉพาะใน description และ fields)

      · ตกแต่งได้แค่ title, description, fields (ชื่อ+ค่า, วางเรียง 3 ช่องต่อแถวเมื่อ inline), footer, สีแถบซ้าย 1 สี, รูป thumbnail/image

      · ข้อความใช้ markdown พื้นฐาน: ตัวหนา, โค้ด, ลิงก์ · ไม่มีสีตัวอักษร ไม่มีตาราง ไม่มีชิปสี · "ชิป" ในนี้คือ inline code

      · field value ยาวได้ 1024 ตัวอักษร · ทั้ง embed 6000 · ปุ่มสูงสุด 5 ปุ่มต่อแถว 5 แถว · ปุ่มลิงก์ต้องเป็นสีเทาเสมอ

      · กดชิปเลขในนี้ = คัดลอกเลข (ใน Discord จริงกดคัดลอกไม่ได้ แต่กดค้าง/ลากได้)

      · แถบซ้ายเป็นสีเดียว gradient ทำไม่ได้ · ปุ่มกว้างตามข้อความ ยืดเต็มแถวไม่ได้ (แยกแถวแล้วขอบไม่ตรงกัน) แถวได้สูงสุด 5 · desktop วาง 5 ปุ่มต่อแถวได้ มือถือ Discord ย่อให้เอง

      · ตัวแก้ file id อัตโนมัติทำไม่ได้ เพราะหน้าขนส่งอยู่หลัง WAF ที่ปฏิเสธทุก client ที่ไม่ใช่เบราว์เซอร์ (ADR-0003) — แต่หลักฐานบ่งว่าขนส่งอัปโหลดทับไฟล์เดิม จึงน่าจะไม่ต้องแก้เลย รอยืนยัน จ. 21 ก.ย.
