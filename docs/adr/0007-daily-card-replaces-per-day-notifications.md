# ADR-0007 · การ์ดประจำวันใบเดียวแทนการแจ้งเตือนรายวันหลายใบ

- สถานะ: ยอมรับ · 2026-09-21
- เกี่ยวข้อง: ADR-0001 (แจ้งเตือนอย่างเดียว) · ADR-0005 (Vercel + cron) · ADR-0006 (เลขประมูล)

## บริบท

หลัง ADR-0006 การ์ด 🎯 ของผู้ใช้เหลือเลขน้อยมาก (สัปดาห์ 21–25 ก.ย. เหลือ 9 เลขจาก 143) เพราะ pattern ที่ตั้งไว้
ชนกลุ่มเลขประมูลเกือบหมด ผู้ใช้จึงขอ "ประกาศประจำวัน" ที่บอกว่า **วันนี้มีเลขอะไรน่าสนใจ** ลงห้องแบบทุกคนเห็น
และให้ลบตัวเองตอนจบวัน

ก่อนหน้านี้ข้อความที่ยิงเข้าห้องอัตโนมัติมี 6 ชนิด ซึ่งซ้อนกันเอง: เช้าวันจันทร์ยิงรวดเดียว 7 ข้อความ
(📅 ตารางรอบใหม่ + 🎯 ห้าใบ + ⏰ เตือนก่อนเปิด) แล้วเงียบไปทั้งสัปดาห์

## การตัดสินใจ

**การ์ดประจำวัน (📣) ใบเดียวต่อวัน** โพสต์ 09:30 ทุกวันที่มีรอบเปิดจองของรถประเภทผู้ใช้:

1. **🎯 เลขในฝันของคุณที่เปิดวันนี้** (ถ้ามี) — ของผู้ใช้มาก่อนของ bot เสมอ
2. **เลขที่ bot คัดให้จากช่วงของวันนั้น** — สายละ 3 เลข ตาม `numerology.json`
   คะแนน = `สายมงคลที่เข้า ×2 + แหล่งที่ตำราตรงกัน + ผลรวมเกรดดีมาก +2` · เลขหนึ่งโผล่สายเดียว
   **ตัดทิ้งเลย**ถ้าติดกลุ่มคู่เลข "ควรเลี่ยง" หรือผลรวมเกรด "ไม่ดีนัก" — การ์ดนี้คือข้อเสนอ ไม่ใช่รายการทั้งหมด
3. **🔜 พรุ่งนี้** — รอบถัดไป + ของที่ต้องเตรียม (ยุบข้อความ ⏰ เตือนก่อนเปิดเดิมมาไว้ตรงนี้)

**ตัดข้อความที่ซ้ำกับการ์ดนี้ออก:** การ์ด 🎯 รายวัน (ยิงอัตโนมัติ) และ ⏰ เตือนก่อนเปิด 1 วัน
— **ปุ่ม 🎯 ที่กดดูเองยังอยู่ครบ** ตัดเฉพาะการยิงเข้าห้องอัตโนมัติ

**เก็บไว้:** 📅 ตารางรอบใหม่ (ภาพรวมสัปดาห์ ใบเดียว) · 🚦 ปิง 09:50 (คนละหน้าที่: "รีบแล้ว") ·
⚠️ หมดเขตจดทะเบียน (คนละเรื่อง) · 🗓️ ตารางหมดอายุ (เป็น error ต้องดัง)

**จบวัน 23:50 ลบเฉพาะการ์ดประจำวัน** (`meta.dailyMessageId`) ไม่แตะข้อความอื่น — ถ้าหาไม่เจอ (โดน 🧹 ไปก่อน)
ถือว่าไม่มีอะไรต้องทำ ไม่ใช่ error · โพสต์ใบใหม่ก็ลบใบค้างก่อนเสมอ กันการ์ดซ้อน

**ไม่โพสต์เมื่อ:** เสาร์-อาทิตย์/วันที่ไม่มีรอบของรถประเภทนี้ · ตารางหมดอายุ (ช่วงเลขไม่ใช่ของจริง)
วันศุกร์ช่อง 🔜 เขียนว่า "สัปดาห์นี้หมดแล้ว · ตารางรอบใหม่ออกเช้าวันจันทร์" เพราะตารางสัปดาห์หน้ายังไม่ออก

## ทำไม 09:30 และทำไมต้อง cron-job.org

ก่อนเปิดจอง 10:00 นานพอให้เลือกเลข และแยกหน้าที่กับปิง 09:50 ชัด ·
Vercel Hobby ยิง cron ได้วันละครั้งต่อ job และ**คลาดได้ ±59 นาที** (21 ก.ย. ตั้ง 08:00 ยิงจริง 08:41 จนพลาดไฟล์ตารางใหม่ที่ขึ้น 08:44)
เวลาที่ต้องตรงจึงอยู่บน cron-job.org ทั้งหมด: 09:30 `/api/cron/daily` · 09:50 `/api/cron/ping` · 23:50 `/api/cron/daily-clear`
`/api/cron/daily` **เช็คตารางให้ในตัว** ด้วย จะได้ไม่พลาดไฟล์ที่ขึ้นหลัง cron 08:00

## ผลที่ตามมา

- ห้องมีข้อความอัตโนมัติ **วันละ 1 ใบ** (+ แผงที่ขยับตาม) แทนที่จะกระจุก 7 ใบตอนเช้าวันจันทร์แล้วเงียบ
- `config.reminders.daysBeforeOpen` ไม่ถูกใช้แล้ว (ถอดออกจาก schema · ไฟล์เก่าที่ยังมี key นี้ Zod จะเมินเฉย ๆ ไม่ error)
- `matchKey`/`wishlistHash` ถูกลบ — ไม่มีการกันแจ้งซ้ำรายช่วงอีกแล้วเพราะไม่ได้แจ้งอัตโนมัติ
  (key เก่าในตาราง `notified` ปล่อยไว้ ไม่กวนใคร)
- เลขที่ bot เสนอ **ไม่ใช่คำแนะนำการลงทุนหรือคำทำนาย** — เป็นการจัดอันดับตามตารางความเชื่อที่ผู้ใช้แก้เองได้
  ทุกเลขบนการ์ดบอกเหตุผลและจำนวนแหล่งที่ตรงกันเสมอ
