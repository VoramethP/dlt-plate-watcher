# ADR-0001 · แจ้งเตือนอย่างเดียว ไม่จองแทน ไม่แตะขั้นตอนยืนยันตัวตน

- สถานะ: ยอมรับ · 2026-09-18

## บริบท

ระบบจองเลขทะเบียนของกรมการขนส่งทางบก (reserve.dlt.go.th) จัดสรรเลขแบบมาก่อนได้ก่อน เปิดวันละช่วง 10:00–16:00 น.
ตั้งแต่ 1 มิ.ย. 2566 ทุกการจองต้องยืนยันตัวตนผ่านแอป ThaID ก่อน และหน้าเว็บอยู่หลัง WAF/บริการกันบอต
ความต้องการดั้งเดิมคือ "agent กดจองให้" แต่การทำอย่างนั้นหมายถึงต้องล็อกอินแทนเจ้าของ ยิงฟอร์มแข่งกับประชาชนคนอื่น
และหลบการตรวจจับบอตของหน่วยงานรัฐ

## การตัดสินใจ

โปรแกรมนี้ **แจ้งเตือนอย่างเดียว** ขอบเขตที่ทำ:

- อ่านตารางเปิดจอง (PDF สาธารณะ) แล้วบอกว่าเลขที่อยากได้จะเปิดวันไหน
- เตือนล่วงหน้าก่อนวันเปิด ปิงก่อนเวลาเปิด และเตือนกำหนดจดทะเบียน
- ส่งเข้า Discord ผ่าน webhook

สิ่งที่**ไม่ทำ** ไม่ว่ากรณีใด:

- ล็อกอิน ThaID แทนผู้ใช้ กรอกเลขบัตรประชาชน หรือกดยืนยันการจอง
- ยิง request เข้าหน้าจอง (`?menu=resv_m`) ทั้งเพื่อจองและเพื่อเช็คสถานะ
- หลบ WAF / CAPTCHA / การตรวจจับบอต (ดู ADR-0003)
- จองหลายเลข หรือจองแทนคนอื่น (ขัดประกาศของขนส่งที่ระบุว่าผู้จองต้องเป็นเจ้าของรถ)

## ผลที่ตามมา

- ผู้ใช้ยังต้องนั่งหน้าจอเองตอน 10:00 น. โปรแกรมทำได้แค่ให้เขามาถึงหน้าจอทันเวลาพร้อมข้อมูลครบ
- โค้ดไม่มีส่วนไหนถือ credential ของผู้ใช้เลย ทำให้เปิด public ได้โดยไม่ต้องกังวลเรื่องข้อมูลส่วนบุคคล
- ฟีเจอร์ใดที่ต้องละเมิดข้อใดข้อหนึ่งข้างบน ให้ปฏิเสธ ไม่ต้องหารือใหม่
