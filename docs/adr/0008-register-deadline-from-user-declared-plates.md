# ADR-0008 · เตือนหมดเขตจดทะเบียนจากเลขที่ผู้ใช้บอกเอง ไม่ใช่จากตารางรายสัปดาห์

- สถานะ: ยอมรับ · 2026-09-24
- เกี่ยวข้อง: ADR-0001 (แจ้งเตือนอย่างเดียว) · ADR-0007 (การ์ดประจำวัน)

## บริบท — ฟีเจอร์ที่ไม่เคยทำงานเลย

24 ก.ย. 2569 ผู้ใช้จองเลข `8ขช 5456` ได้จริง (ต้องจดทะเบียนภายใน 26 ต.ค.)
ตอนจะยืนยันว่า bot จะเตือนให้ กลับพบว่า **⚠️ เตือนหมดเขตจดทะเบียนยิงไม่ได้ในการใช้งานจริง**:

```ts
const mine = schedule.entries.filter(...)          // ตาราง "สัปดาห์ปัจจุบัน" เท่านั้น
const untilDeadline = daysBetween(today, e.registerBy);
if (config.reminders.daysBeforeRegisterDeadline.includes(untilDeadline)) push(...)
```

ขนส่งอัปโหลดไฟล์ตารางทับทุกเช้าวันจันทร์ **แถวของวันที่ผู้ใช้จองได้จึงหายไปจาก PDF ภายในสัปดาห์เดียว**
ขณะที่กำหนดจดทะเบียนอยู่ห่างออกไป ~30 วัน · และแถวของสัปดาห์ใหม่ก็มี `registerBy` ห่าง ~30 วันเสมอ
→ `untilDeadline` แทบไม่มีทางเท่ากับ 7 หรือ 1 · ⚠️ จึงยิงได้เฉพาะตอนตาราง stale ค้างนานผิดปกติเท่านั้น

เทสเดิมผ่านเพราะใช้ตารางสมมติที่ `registerBy` ใกล้วันที่ทดสอบพอดี — **บั๊กชนิด "เงียบจนไม่มีใครรู้ว่าพัง"
ตัวที่สามในสัปดาห์เดียว** (ต่อจาก `clearDaily` รายงานสำเร็จทั้งที่ล้มเหลว และ id ของ Discord เพี้ยนจาก jsonb)

## การตัดสินใจ

**เลิกคำนวณกำหนดจดทะเบียนจากตาราง** แล้วเก็บ "เลขที่จองได้แล้ว" เป็นข้อมูลของตัวเอง:

- **ปุ่ม 🏆 จองได้แล้ว** บนแผง (แถว "ทำ" · รวมเป็น 5 ปุ่มพอดีลิมิตแถวละ 5)
  modal 4 ช่อง: **เลขที่จองได้** · **วันหมดเขต** (ไม่ใส่ = หาจากตารางสัปดาห์นี้ให้) ·
  **หมวดอักษร** (ไม่ใส่ = หาให้) · **จดทะเบียนแล้ว/ยกเลิก** (ใส่เลขเพื่อหยุดเตือน)
- เก็บที่ **`meta.won`** เป็น JSON array `{prefix, number, registerBy, by, at}` — **ไม่ต้อง migration**
  และใช้ได้ทั้ง `fileStore` และ Postgres เพราะทั้งคู่มี `getMeta`/`setMeta` อยู่แล้ว
  (ตาราง `wishlist` ใช้ไม่ได้: คอลัมน์เป็น `number` ตัวเดียว ไม่มีที่เก็บหมวดกับวันหมดเขต)
- `planNotifications` เตือนจากรายการนี้ ตาม `reminders.daysBeforeRegisterDeadline` (ค่าเริ่มต้น 7 และ 1 วัน)
  **อยู่นอกเงื่อนไข stale** เพราะกำหนดจดทะเบียนเดินต่อไม่ว่าตารางจะเป็นยังไง
- **ผู้ใช้เลือกให้เตือนเป็นข้อความ ⚠️ แยกใบเท่านั้น** ไม่เพิ่มบรรทัดบนการ์ดประจำวัน (ให้ห้องเงียบที่สุด)
  ข้อความจะดังขึ้นเมื่อเหลือ ≤1 วัน (🚨 สีแดง)

## ทำไมต้องให้ผู้ใช้กดบอกเอง

bot ไม่รู้และไม่มีสิทธิ์รู้ว่าใครจองอะไรได้ — มันไม่ยิงหน้าจองของขนส่งและไม่ล็อกอิน ThaID (ADR-0001/0003)
ข้อมูลนี้จึงต้องมาจากคนเท่านั้น · ข้อความตอบกลับเขียนกำกับไว้ว่า "ข้อมูลนี้ผู้ใช้เป็นคนบอก bot ไม่ได้เช็คกับระบบขนส่ง"

## ผลที่ตามมา

- ไม่กดปุ่ม 🏆 = ไม่มีการเตือน (เหมือนเดิมทุกประการ แต่ตอนนี้ *มีทาง* ให้เตือนได้จริง)
- `reminderEmbed`/`reminderKey` เดิมถูกลบทิ้ง · key ใหม่คือ `won:<หมวด>:<เลข>:<วันหมดเขต>:<เหลือกี่วัน>`
- ข้อความ ⚠️ จะถูกกวาดทิ้งเช้าวันถัดไปตาม `DAILY_SWEEP` (ADR-0007) — ถ้าอยากให้ค้างนานขึ้น
  เพิ่มวันเตือนใน `reminders.daysBeforeRegisterDeadline` เช่น `[14, 7, 3, 1]`
- ปุ่มบนแผงครบ 10 ปุ่ม → `DISCORD_BUTTONS_PER_ROW=2` จะได้ 6 แถวซึ่งเกินลิมิต 5 แถวของ Discord
  `panelRows()` จึงถอยกลับเป็นกลุ่มละแถวอัตโนมัติ (มีเทสคุม)
