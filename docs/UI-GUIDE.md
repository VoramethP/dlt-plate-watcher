# คู่มือปุ่มใน Discord

เนื้อหาเดียวกับที่ bot ตอบเมื่อกด **❓ คู่มือ** บนแผงควบคุม (`src/notify/discord.ts › guideEmbeds`) — แก้ที่ไหนให้แก้อีกที่ด้วย

ปุ่มทำงานผ่าน Interactions Endpoint บน Vercel (ADR-0005) — ไม่ต้องมี process รันค้างที่ไหน · ตรรกะ route อยู่ใน `src/notify/interactions.ts`

## 🏠 landing panel (แผงหลัก)

อยู่ล่างสุดของช่องเสมอ: ย้ายมาล่างสุดทุกครั้งที่แจ้งเตือน (cron 08:00 / 09:30 / 09:50 หรือกด 🔄) และหลังกด 🧹 · หาไม่เจอพิมพ์ `/panel` (ลงทะเบียนครั้งเดียวด้วย `npm run register`) · ถ้า bot มีสิทธิ์ Pin Messages จะปักหมุดให้ด้วย

**บนแผงบอกโดยไม่ต้องกด:** สถานะวันนี้ (🔥 วันนี้เปิด / ⏳ เลขในฝันเปิดครั้งถัดไปอีกกี่วัน / 😴 หมดสัปดาห์ / 🗓️ ตารางหมดอายุ) · wishlist ย่อ · เช็คล่าสุดเมื่อไหร่ · ตารางสัปดาห์ไหน

## 🔮 เลขศาสตร์ (`numerology.json`)

การ์ดเลขในฝัน ปุ่ม 📋 และคำตอบตอนกรอกเลข จะบอกว่าเลขนั้นเข้ากลุ่มไหน ตามตารางใน `numerology.json` ซึ่ง**รวบรวมจากแหล่งเผยแพร่สาธารณะ 6 แหล่ง** (รายชื่ออยู่ในไฟล์ใต้ `sources`) ไม่ได้แต่งเอง

- **ทุกรายการบอกว่ามาจากแหล่งไหน** (`pairSources`, `sumGrades[].sources`) และ bot แสดงจำนวนแหล่งที่เห็นตรงกัน เช่น "คู่เลข 24 · 3 แหล่งตรงกัน" · ถ้าแหล่งขัดกันจะมี `conflict` และ bot บอกว่า "บางแหล่งเห็นต่าง"
- ตารางค่าตัวอักษร 3 แหล่งตรงกันทุกตัว · ผลรวม = เลขนำหมวด + ค่าตัวอักษร + เลข 4 หลัก (ตามที่ทุกแหล่งใช้กับตารางผลรวมสองหลัก)
- กลุ่มคู่เลขใช้ชื่อหมวดตามที่แหล่งใช้ (แคล้วคลาด · เมตตามหานิยม · อำนาจบารมี · โชคลาภการเงิน) และมีกลุ่ม **ควรเลี่ยง** ที่ bot จะเตือน แต่ไม่ตัดเลขออกให้
- ยังคงเป็น**ความเชื่อ ไม่ใช่ข้อเท็จจริง** แก้ได้ทุกช่อง bot อ่านไฟล์ใหม่ทุกครั้ง · ลบไฟล์ทิ้ง = ไม่แสดงส่วนนี้เลย

## 🔨 เลขที่ขนส่งกันไว้ประมูล (`auction-rules.json`)

กรมการขนส่งทางบกกันหมายเลข "ซึ่งเป็นที่ต้องการหรือเป็นที่นิยมของประชาชน" **301 หมายเลขต่อหนึ่งหมวดอักษร**
ไปประมูลที่ tabienrod.com เลขกลุ่มนี้**ไม่เข้าระบบจองออนไลน์ตั้งแต่แรก** — กดตอน 10:00 ยังไงก็ไม่ได้

| กลุ่มตามประกาศ | ตัวอย่าง | จำนวน |
|---|---|---|
| เลขสี่ตัวเหมือน | 1111 … 9999 | 9 |
| เลขสามตัวเหมือน · สองตัวเหมือน · เลขตัวเดียว · เลขคู่ 8 เลขคู่ 9 | 555 · 77 · 9 · 8899 | 33 |
| เลขหลักพัน · เลขเรียง · เลขคู่ (aabb/abba/abab) | 5000 · 789 · 6789 · 6644 6446 6464 | 259 |

- bot **ไม่ลบเลขพวกนี้ทิ้ง** แต่ย้ายไปช่อง 🔨 ของตัวเองในการ์ด 🎯 และปุ่ม 📋 พร้อมชื่อกลุ่ม
- **วันไหนตรงเงื่อนไขแต่เป็นเลขประมูลล้วน → ไม่แจ้งเตือนและไม่ปิง 09:50** (ไม่มีอะไรให้กด) ยังดูได้จากปุ่ม 🎯
- ข้อมูลมาจาก**ตารางแนบท้ายประกาศฯ** ไม่ได้ถามระบบขนส่ง (ADR-0001/0003) · สร้างไฟล์ใหม่ด้วย `npm run gen:auction`
- ประกาศไม่ครอบคลุมทุกกรณี (ขนส่งจังหวัดกันเลขเพิ่มได้ · เลขประมูลที่ไม่มีคนเอาถูกปล่อยกลับเข้าระบบจอง)
  → เจอเลขที่กดไม่ได้ ใส่ในช่อง **🔨** ของปุ่ม 🔢 แล้ว bot จำให้ · เอากลับด้วยช่อง **เพิ่ม**

## 📣 การ์ดประจำวัน (ADR-0007)

**ใบเดียวต่อวัน ทุกคนในห้องเห็น** โพสต์ 09:30 ทุกวันที่มีรอบเปิดจองของรถประเภทคุณ แล้ว **ลบตัวเองตอน 23:50**

| ส่วนของการ์ด | เนื้อหา |
|---|---|
| 🎯 เลขในฝันของคุณที่เปิดวันนี้ | เลขใน wishlist ที่เปิดวันนี้และจองออนไลน์ได้ (ของคุณมาก่อนของ bot เสมอ) |
| สายละ 3 เลข (🛡️ 💗 👑 💰) | เลขที่ bot คัดจากช่วงของวันนั้น · คะแนน = สายมงคลที่เข้า ×2 + แหล่งที่ตำราตรงกัน + ผลรวมดีมาก +2 · **ตัดเลขที่ตำราบอกให้เลี่ยงและผลรวมเกรด "ไม่ดีนัก" ออก** · เลขหนึ่งโผล่สายเดียว |
| 🔜 พรุ่งนี้ | รอบถัดไป + เลขในฝันที่จะเปิด + ของที่ต้องเตรียม (ThaID · เลขตัวถัง · ชื่อตรงบัตร) · วันศุกร์เขียนว่ารอตารางรอบใหม่เช้าจันทร์ |
| ปุ่มใต้การ์ด | 🔢 เพิ่มเลขที่ถูกใจเข้า wishlist ทันที · 📤 แชร์เลข · 🌐 เข้าสู่เว็บไซต์ |

- **ไม่โพสต์**: เสาร์-อาทิตย์ (ไม่มีรอบ) · ตารางหมดอายุ (ช่วงเลขไม่ใช่ของจริง ปล่อยให้ 🗓️ ทำงานแทน)
- โพสต์ใบใหม่จะลบใบค้างของเมื่อวานก่อนเสมอ · ลบตอน 23:50 แล้วไม่เจอ (โดน 🧹 ไปก่อน) ไม่ถือเป็น error
- ดูหน้าตาบนเครื่องได้ด้วย `npm run dev -- daily` (ไม่ส่ง Discord)
