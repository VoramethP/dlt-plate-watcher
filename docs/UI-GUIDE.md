# คู่มือปุ่มใน Discord

เนื้อหาเดียวกับที่ bot ตอบเมื่อกด **❓ คู่มือ** บนแผงควบคุม (`src/notify/discord.ts › guideEmbeds`) — แก้ที่ไหนให้แก้อีกที่ด้วย

ปุ่มทำงานผ่าน Interactions Endpoint บน Vercel (ADR-0005) — ไม่ต้องมี process รันค้างที่ไหน · ตรรกะ route อยู่ใน `src/notify/interactions.ts`

## 🏠 landing panel (แผงหลัก)

อยู่ล่างสุดของช่องเสมอ: ย้ายมาล่างสุดทุกครั้งที่แจ้งเตือน (cron 08:00 / 09:50 หรือกด 🔄) และหลังกด 🧹 · หาไม่เจอพิมพ์ `/panel` (ลงทะเบียนครั้งเดียวด้วย `npm run register`) · ถ้า bot มีสิทธิ์ Pin Messages จะปักหมุดให้ด้วย

**บนแผงบอกโดยไม่ต้องกด:** สถานะวันนี้ (🔥 วันนี้เปิด / ⏳ เลขในฝันเปิดครั้งถัดไปอีกกี่วัน / 😴 หมดสัปดาห์ / 🗓️ ตารางหมดอายุ) · wishlist ย่อ · เช็คล่าสุดเมื่อไหร่ · ตารางสัปดาห์ไหน

## 🔮 เลขศาสตร์ (`numerology.json`)

การ์ดเลขในฝัน ปุ่ม 📋 และคำตอบตอนกรอกเลข จะบอกว่าเลขนั้นเข้ากลุ่มไหน ตามตารางใน `numerology.json` ซึ่ง**รวบรวมจากแหล่งเผยแพร่สาธารณะ 6 แหล่ง** (รายชื่ออยู่ในไฟล์ใต้ `sources`) ไม่ได้แต่งเอง

- **ทุกรายการบอกว่ามาจากแหล่งไหน** (`pairSources`, `sumGrades[].sources`) และ bot แสดงจำนวนแหล่งที่เห็นตรงกัน เช่น "คู่เลข 24 · 3 แหล่งตรงกัน" · ถ้าแหล่งขัดกันจะมี `conflict` และ bot บอกว่า "บางแหล่งเห็นต่าง"
- ตารางค่าตัวอักษร 3 แหล่งตรงกันทุกตัว · ผลรวม = เลขนำหมวด + ค่าตัวอักษร + เลข 4 หลัก (ตามที่ทุกแหล่งใช้กับตารางผลรวมสองหลัก)
- กลุ่มคู่เลขใช้ชื่อหมวดตามที่แหล่งใช้ (แคล้วคลาด · เมตตามหานิยม · อำนาจบารมี · โชคลาภการเงิน) และมีกลุ่ม **ควรเลี่ยง** ที่ bot จะเตือน แต่ไม่ตัดเลขออกให้
- ยังคงเป็น**ความเชื่อ ไม่ใช่ข้อเท็จจริง** แก้ได้ทุกช่อง bot อ่านไฟล์ใหม่ทุกครั้ง · ลบไฟล์ทิ้ง = ไม่แสดงส่วนนี้เลย
