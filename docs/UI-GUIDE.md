# คู่มือปุ่มใน Discord

เนื้อหาเดียวกับที่ bot ตอบเมื่อกด **❓ คู่มือ** บนแผงควบคุม (`src/notify/discord.ts › guideEmbeds`) — แก้ที่ไหนให้แก้อีกที่ด้วย

## ปุ่มใต้ข้อความแจ้งเตือน (มีทุกข้อความ)

| ปุ่ม | ทำอะไร | ไม่ทำอะไร |
|---|---|---|
| 🔢 กรอกเลขที่อยากจอง | ฟอร์ม 3 ช่อง **เพิ่ม** (หลายเลข คั่นด้วย , หรือเว้นวรรค) · **ไม่อยากได้** ตัดเลขออกจากทุกรูปแบบ เช่น จองได้แล้วหรือ pattern จับได้แต่ไม่ชอบ (`wishlist.exclude`) · **ลบ** ออกจากรายการไหนก็ได้ → แก้ `watch.config.json` · bot ตอบรายเลขว่าเปิดจองวันไหน ซ้ำไหม ช่วงนั้นผ่านไปแล้วไหม ใครในเซิร์ฟเวอร์เล็งไว้ก่อน (จำไว้ใน `.state`) และ 💡 ถ้าเลขนั้นถูก pattern/ผลรวมครอบอยู่แล้ว | ไม่จองแทน · ไม่เช็คกับระบบขนส่งว่าเลขถูกจองแล้ว |
| 📋 เลขที่เฝ้าอยู่ | ทุกเลขใน wishlist ตอนนี้ พร้อมใครเพิ่ม และจะเปิดจองวันไหน (🔭 ยังไม่ถึงคิว · ⏳ กำลังมา · 🔥 วันนี้ · ⏪ เปิดไปแล้ว) ใช้ตรวจว่าลืมลบเลขไหน | — |
| 📤 แชร์เลข | ข้อความนั้นในรูปข้อความล้วนใน code block → desktop ชี้เมาส์มีปุ่มคัดลอก มือถือกดค้าง เอาไปส่งครอบครัวช่วยเลือกเลข | — |
| 🧹 ลบประวัติแชตเก่า | ลบข้อความเก่าของ bot ในช่องนี้ ≤100 ข้อความล่าสุด เก็บข้อความที่กดไว้ | ไม่แตะข้อความของคนอื่น |
| 🌐 เข้าสู่เว็บไซต์ | ลิงก์ไปหน้าจอง reserve.dlt.go.th (เปิด 10:00–16:00 ตามตาราง ต้องยืนยัน ThaID) | ไม่มี request จากโค้ดไปหาขนส่ง |

## แผงควบคุม (ปุ่มลัดคำสั่ง)

อยู่ล่างสุดของช่องเสมอ: bot โพสต์ตอนเริ่ม `watch` และย้ายมาล่างสุดทุกครั้งที่แจ้งเตือน · หาไม่เจอพิมพ์ `/panel` · ถ้า bot มีสิทธิ์ Pin Messages จะปักหมุดให้ด้วย

| ปุ่ม | เท่ากับ | ได้อะไร |
|---|---|---|
| 📅 ตารางสัปดาห์นี้ | `npm run schedule` | ตารางเปิดจองทั้ง 3 ประเภทรถ |
| 🎯 เลขในฝันรอบนี้ | `npm run match` | เลขใน wishlist ที่จะเปิดสัปดาห์นี้ พร้อมเหตุผล |
| 🔄 เช็คตอนนี้ | `npm run check` | ดึงตารางแล้วส่งแจ้งเตือนเฉพาะที่ยังไม่เคยส่ง |
| 🧭 สถานะ bot | แทน `npm run watch` | ออนไลน์นานเท่าไหร่ · wishlist · รอบ check/ปิงถัดไป |
| 📜 ดูประวัติแชต | — | รายการที่ bot เคยแจ้ง (จาก `.state/notified.json`) ล่าสุดก่อน |
| ❓ คู่มือ | — | คู่มือนี้ในรูป embed |

ทุกคำตอบของแผงเป็นแบบ ephemeral (เห็นเฉพาะคนกด) จึงกดเล่นได้โดยไม่รบกวนช่อง
